# secure-network-
🚀 Excited to share my latest hands-on networking and cybersecurity lab built on PNETLab!

I’ve been working on designing and implementing a robust enterprise network topology to test advanced routing, switching, and firewall security policies. Here is a quick breakdown of what this lab includes:

Segmentation & Routing: Configured multiple VLANs (VLAN-HR and VLAN-IT) communicating securely through a FortiGate Next-Generation Firewall.

Firewall & NAT Integration: Implemented clean security zones (LAN, DMZ, WAN) with proper Source NAT and Static Routing configuration pointing to the upstream router (R1) to ensure seamless internet traffic flow.

Advanced DNAT (Virtual IPs): Configured Destination NAT / Port Forwarding so that external/remote endpoints (like 192.168.2.2) can securely access internal services (such as RDP on 172.16.10.10 in the DMZ).

Troubleshooting & Deep Inspection: Used the FortiGate CLI (diagnose sniffer packet and get system session list) to analyze real-time sessions, verify packet translation, and ensure the traffic paths matched the security rules.

Building and troubleshooting these environments hands-on is the best way to master network infrastructure and perimeter security. Looking forward to expanding this lab further with IPsec VPNs and advanced security profiles! 💡🔒
